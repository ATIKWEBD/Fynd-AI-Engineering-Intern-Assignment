📖 Project Overview

This repository contains my solution for the AI Engineering Internship assessment at Fynd. The goal was to demonstrate "Rapid Prototyping" and "Prompt Engineering" skills by building a real-world AI feedback loop.

The Solution is divided into two parts:

Task 1 (Research): A scientific evaluation of 3 prompting strategies to classify Yelp review sentiments using Google Gemini.

Task 2 (Product): A full-stack Dual-Dashboard Web App where customers submit feedback and managers get instant, actionable AI insights.

🧠 Task 1: Prompt Engineering Experiment

I conducted a controlled experiment on a dataset of Yelp reviews to determine the best prompting strategy for sentiment analysis.

Methodology & Data Filtering:

Dataset: Sampled from Yelp Reviews (Kaggle).

Sample Size: ~180 Valid Rows.

Note: While 200 rows were processed, ~10% were filtered out during evaluation due to the LLM's Safety Settings blocking reviews with profanity or strict Rate Limiting on the free API tier.

Metric: I introduced "Off-by-One Accuracy" (prediction within ±1 star) alongside exact accuracy, as human ratings are subjective.

🛠️ Task 2: AI Feedback Loop (Web App)

I built a unified web application using Streamlit that serves two distinct user groups.

Features

For Customers (User Tab):

Clean, mobile-friendly interface to rate and review.

Real-time AI Response: The user gets an immediate, empathetic reply generated by Gemini.

For Managers (Admin Tab):

Secure Access: Password-protected dashboard (fynd123).

Live Analytics: Visual breakdown of sentiment trends.

Actionable Insights: The AI automatically extracts a 5-word summary and a concrete action item (e.g., "Inspect kitchen hygiene") for every review.

Engineering Decisions

Model: Switched to Gemini 2.0 Flash for superior reasoning speed compared to 1.5.

Robustness: Implemented JSON Mode enforcement to prevent the app from crashing if the AI outputs unstructured text.

Graceful Degradation: If the API Quota is hit (Error 429), the app falls back to a "Manual Review" state instead of breaking.

💻 Tech Stack

Language: Python 3.9+

Frontend/Backend: Streamlit

AI Model: Google Gemini API

Data Handling: Pandas (CSV persistence)

Environment Management: python-dotenv
